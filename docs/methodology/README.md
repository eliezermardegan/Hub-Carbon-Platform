# Methodology

The platform will implement methodologies rather than redistribute protected standards documents.

Initial scope: GHG Protocol Corporate Standard; Scope 2 market/location based; Scope 3 Categories 1–15; ISO 14064-1 aligned inventory structures; IPCC GWP versioning; jurisdictional reporting mappings; Brazil PBGHG / ABNT-ISO implementation / SBCE readiness.

All methodology implementations must be versioned and tested.
