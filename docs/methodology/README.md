# Methodology

The platform will implement methodologies rather than redistribute protected standards documents.

Initial methodology scope:

- GHG Protocol Corporate Standard
- Scope 2 market-based and location-based accounting
- Scope 3 Categories 1–15
- ISO 14064-1 aligned inventory structures
- IPCC GWP versioning
- jurisdictional reporting mappings
- Brazil-specific PBGHG / ABNT-ISO implementation / SBCE readiness

All methodology implementations must be versioned and tested.
