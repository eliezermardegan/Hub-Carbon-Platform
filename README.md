# Hub Carbon Platform

Open-source foundation for an auditable, automated and jurisdiction-aware carbon accounting platform.

## Mission

Turn financial, procurement, operational and document data into traceable GHG activity data, deterministic emissions calculations, audit evidence, reporting outputs and decarbonization insights.

## Core principles

- **Licensed reuse only:** third-party code is incorporated only when its license permits it.
- **Provenance by default:** every imported component and material dataset has source and license metadata.
- **Deterministic carbon calculations:** AI may extract, classify and suggest; the calculation engine is deterministic.
- **Auditability:** inventory results must be traceable from total -> category -> activity -> source evidence -> factor -> calculation.
- **Data quality is explicit:** primary, activity-based, spend-based and unresolved data are never silently conflated.
- **Regulation is versioned:** methodologies and jurisdictional rules are represented as versioned configuration/code, not copied standards documents.
- **Brazil-ready, globally extensible:** global methodology first, with Brazil-specific modules for PBGHG, ABNT/ISO implementation and SBCE readiness.
